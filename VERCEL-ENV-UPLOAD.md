# 🚀 Add .env File to Vercel

## ✅ **Simple .env Upload Method**

You can upload your existing `.env` file directly to Vercel!

### **Step 1: Go to Vercel**
1. **Visit**: https://vercel.com/NeilLopes-9973/taskflow-student-manager
2. **Click**: "Settings" tab
3. **Select**: "Environment Variables"

### **Step 2: Upload .env File**
1. **Click**: "Upload .env" button
2. **Select**: Your local `.env` file
3. **Upload**: The file contains all 6 Firebase variables

### **Step 3: Deploy**
1. **Redeploy** your application
2. **Wait 2-3 minutes** for deployment
3. **Test** your app
